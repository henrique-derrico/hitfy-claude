Bem-vindo

O que você está vendo?

O que é o Claude Code

É o terminal de desenvolvimento da Anthropic — um assistente de IA que vive dentro do repositório, com acesso aos arquivos, ao Git, ao Jira e ao GitLab. Em vez de copiar e colar código entre o ChatGPT e o editor, o dev conversa direto no terminal e o Claude executa.

O que é este mapa

Esta é a configuração que fizemos do Claude Code para o repositório Hitfy v4. Cada nó é um pedaço dessa configuração: comandos slash, agentes especializados, skills (base de conhecimento do time), hooks (proteções automáticas) e integrações externas via MCP. As setas mostram como tudo se conecta.

Como ler o gráfico

Cada cor representa uma camada da arquitetura; cada ícone identifica o tipo de elemento. As setas têm cores e estilos diferentes — sólidas são invocações, tracejadas são auto-delegações ou proteções. Clique em qualquer nó para ver o que ele faz e o fluxo passo a passo. Use o "Tour guiado" no canto superior direito para um passeio narrado.

Por que isso importa

A configuração transforma trabalho manual repetitivo (escrever branch, commit, abrir MR, postar RCA no Jira) em fluxo automático. O dev foca no problema; o Claude cuida do boilerplate. Cada agente segue padrões documentados nas skills, então o código gerado é consistente com o resto do repositório.
